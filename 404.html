首次迁移

先在“有数据”的设备登录

  1. V3 有数据时，先在 V3 导出 JSON 备份。
  2. MacBook 打开 GitHub Pages 上的 V4，先导入这份 JSON。
  3. 配置 Supabase，并登录账号。
  4. 点击一次“立即同步”，把 Mac 数据作为第一份云端数据。
  5. 再在 iPhone 安装 V4，用同一个账号登录并读取云端数据。
iPhone

安装到主屏幕

  1. Safari 打开 GitHub Pages 的 HTTPS 地址。
  2. 分享 → “添加到主屏幕”。
  3. 从“天蓬 VitoShawn”图标启动。
  4. 登录与 MacBook 相同账号。
MacBook

安装到 Dock

  1. Safari 打开同一个 GitHub Pages 地址。
  2. 文件 → “添加到 Dock”。
  3. 从 Dock / Spotlight 启动“天蓬 VitoShawn”。
  4. 登录与 iPhone 相同账号。
本地保险

JSON 备份仍然保留

云同步之外，仍建议偶尔导出一份 JSON。它不会上传到 GitHub。

冲突策略

适合你个人顺序使用

V4 采用“最后一次成功保存为准”。正常在 iPhone 记素材、回 MacBook 写稿没有问题；不建议两台设备同时编辑同一页。

离线时先存本地；重新联网后自动尝试上传。
